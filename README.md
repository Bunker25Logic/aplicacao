Uma biblioteca digital de frases famosas de animes, filmes, músicas e outras obras marcantes da cultura pop.

O aplicativo permite explorar frases inspiradoras, salvar favoritas e receber notificações automáticas duas vezes ao dia com frases aleatórias da biblioteca.

---

## 🚀 Sobre o Projeto

A **Aplicação** é um app mobile desenvolvido com **React Native (Expo)** que reúne frases icônicas em um só lugar.

O projeto está funcional e pode ser considerado em sua versão final, já estando **disponível para download na BunkerStore** através do meu portfólio, e preparado para futura publicação na Play Store.

---

## ✨ Funcionalidades

- 📖 Biblioteca de frases organizadas
- ⭐ Sistema de favoritos
- 📂 Aba exclusiva para frases salvas
- 🎲 Seleção aleatória de frases
- 🔔 Notificações automáticas diárias:
  - 🌅 Uma notificação pela manhã
  - 🌇 Uma no início da noite
- 💾 Armazenamento local dos favoritos

---

## 🛠️ Tecnologias Utilizadas

- React Native
- Expo
- Expo Notifications
- Async Storage
- JavaScript

---

## 📱 Como Executar o Projeto

### 1️⃣ Instale as dependências

```bash
npm install
```

### 2️⃣ Execute o projeto

```bash
npx expo start
```

Você poderá rodar o app:

- Em um emulador Android
- Em um emulador iOS
- Em um dispositivo físico utilizando o aplicativo Expo Go

---

## 🔔 Sistema de Notificações

O aplicativo envia automaticamente duas notificações por dia contendo frases aleatórias da biblioteca:

- 🌅 Uma no período da manhã
- 🌇 Uma no início da noite

As notificações utilizam o sistema nativo do dispositivo.
